# 单细胞簇指派的客观 tie-break（`docs/03` §19）

生成脚本 `scripts/21_scrna_cluster_tiebreak.py`。
**规则写定于任何 tie-break 结果产生之前**；聚类与 top-30 markers 沿用 `scripts/13` 已锁定的结果，不重跑、不改分辨率。

- 超几何检验总体：**33538 个被检测基因全集**（§19.2 第 3 条）
- 每簇抽取 `top-30` 差异表达基因，检验其在 marker 集中的超几何富集
- 显著性阈值 α = 0.05；未达阈值一律标 `Unassigned`

> **实现更正留痕**：本脚本初版把超几何总体错设为「top-30 里出现过的基因」（33538 的一个子集），该总体已被差异表达筛选富集过，会把富集人为压低，导致约四成细胞被弃权。已按 §19.2 第 3 条改回**被检测基因全集**。这是实现 bug 的修复，**不是**看到结果后改口径；规则本身一字未动。

### 1.2 弃权簇的真实身份（逐个查证，不靠印象）

逐簇核对 top-30 后，6 个弃权簇分属三种完全不同的情况，**不能用一句「marker 集不够用」概括**：

| 情况 | 簇 | 判据 |
|---|---|---|
| **低质量 / ambient 簇** | 4、5、38 | top markers 是 `RPL34`/`RPS3A`/`RPS27A`（核糖体）、`MALAT1`/`MT-CO1`/`MT-CO2`、`GAPDH`/`IFI27` —— 无细胞身份信息，**弃权正确，且这些细胞本就不该进参考谱** |
| **增殖态细胞** | 24 | `HMGB2`/`MKI67`/`STMN1`/`TUBA1B`/`TMPO` —— 是增殖细胞的标记，不是某个细胞**类型**的标记 |
| **marker 集覆盖不到的基质/血管亚型** | 13、34 | 见下 |

**簇 34 的真实身份（此前一度被误记为成纤维细胞，此处更正）**：其 top-30 为 `IGFBP2`、`AKAP12`、`POSTN`、`AEBP1`、**`COL6A1`**、`AFAP1`、**`COL4A2`**、`CALD1`、`SPARCL1`、`PTPRG`、`CAV1`、`ITGB5`、`VEGFA`、`MYH10` —— 这是**血管/周细胞样基质程序**，既不是成纤维细胞（无 `COL1A1`/`COL1A2`/`DCN`/`LUM`），也不是本项目 `Endothelial` 集所列的经典内皮（无 `PECAM1`/`VWF`/`CDH5`/`CLDN5`）。**12 个候选集全都覆盖不到它，因此判 `Unassigned` 是正确行为**——若沿用 `scripts/13` 的打分法，它会被错分给 Melanocyte。

**簇 37 是真正的成纤维细胞**：top-30 含 `COL1A2`、`COL11A1`、`TNC`、`SFRP1`、`IGFBP7`、`A2M``，命中 `Fibroblast` 集的 `COL1A2`，富集 p = 6.2e-03。**参考谱中 Fibroblast 从 0% 恢复到 3.8%，正是这次修复的目的。**

**但不回避它的后果**：`Unassigned` 占 15.1%，其中含一整簇真实的血管/周细胞样基质细胞。去卷积时这部分表达会被归到其余谱上，**在补齐 marker 集之前，本参考谱不能声称是 12 类精细分解**。

**11/41 个簇的指派发生变化，6 个被判为 `Unassigned`。**

## 三、这个改动影响什么、不影响什么

| 项 | 是否受影响 |
|---|---|
| 去卷积参考谱（GSE294273 → bulk 分解） | **受影响**，这就是本次修复的目的 |
| 模块 2 肿瘤内在状态打分（GSE308433/434） | **不受影响**——该模块只用肿瘤核，不做细胞类型指派 |
| 模块 2b 基因剂量（GSE308433） | **不受影响**——纯 CNV 统计量，与细胞组成无关 |
| IMPRES 与建模（`docs/05`–`docs/07`） | **不受影响**——纯 bulk 表达 |

**已记录的残余限制**：富集检验只解决**指派**，不改变**聚类**。若某类细胞在转录组上与其邻近类型本就连续（如 CD8 T 与 NK），Leiden 会不会切出边界本身就有不确定性，这一点不因 tie-break 而消失（§19.4）。
