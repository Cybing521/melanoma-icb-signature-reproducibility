## 一、主方案题目

**《配对活检驱动的黑色素瘤免疫检查点治疗耐药细胞生态位解析及其跨队列验证》**

> **题名口径提示（2026-10-06 核对后）**："配对活检"仅指 GSE91061 的 Pre/On 同病灶配对（65 例中 43 例有完整配对）与 GSE308434/435 的 42 份同活检肿瘤—TCR 配对；后者的 34 例中仅 7 例有多活检，且无应答标签，**TCR 侧按 ≥200 个 T 细胞过滤后仅剩 18 个文库**。"生态位"指肿瘤内在状态与 TCR 克隆性特征的耦合结构，而非免疫细胞比例构成——公开数据中没有可做免疫细胞比例刻画的 snRNA 队列。定稿题名前建议据模块 2 的实际产出再定一次。

## 二、问题依据

晚期黑色素瘤的一线治疗是免疫检查点抑制剂（ICB），但仅部分患者获得持久缓解，其余在数月内进展。临床上真正的决策点有两个：给药前判断谁应答，以及应答后判断谁正在走向耐药。目前常规检测（PD-L1 免疫组化、肿瘤突变负荷）在黑色素瘤中的判别力有限，且无法回答"耐药是怎么建立起来的"。

已经比较清楚的部分：基线瘤内免疫细胞组成、IFN-γ 应答程序、耗竭相关特征与 ICB 应答相关；TIDE 一类工具把这些特征汇总成连续分数。

仍然模糊的部分：耐药在治疗过程中通过什么样的细胞生态位重配建立；多数应答预测模型把终点换成生存，训练人群是原发与转移灶混合的回顾性队列，而生存并不是给药当刻能拿到的结局；模型的评价通常只报告 AUC，缺少校准与决策层面的分析，也缺少"在已进展样本上会怎样"的边界检验。

## 三、研究现状：已做熟的套路与仍可切入的缺口

### 已被大量重复的套路

| 套路 | 为什么不再构成增量 |
|---|---|
| TCGA-SKCM 全队列 LASSO / Cox 筛基因 → "N 基因预后模型" + KM 曲线 | 终点是生存，不是给药决策时点可得的结局；模型换一批基因仍成立，说明抓的是数据集特征而非机制 |
| 单细胞找差异基因 → 细胞通讯 → 在 TCGA 里验证 → 画 ROC 与生存 | 与已有大量工作重合；单细胞结论未在独立 ICB 应答队列中被验证过 |
| 直接把 TIDE / IFN-γ / 炎症签名套进黑色素瘤队列 | 属于工具迁移，不构成新的证据层 |

### 仍可切入的真实缺口

1. **同一份活检内肿瘤内在状态与 TCR 克隆型配对的人体数据稀缺。** GSE308434 / GSE308435 / GSE308433 是同一研究的三个姊妹系列，提供 34 例转移性黑色素瘤患者共 42 份治疗过程中的活检单核转录组、配套 TCR 序列与全基因组。**但必须如实标注其边界**：42 份中仅 7 例患者有多活检，且公开 deposit **不含应答标签**，因此只能做同活检内的肿瘤–免疫配对刻画与描述性比较，**不能做"进展 vs 应答"的组间推断**。这一点在 2026-10-06 核对后已修正原文的夸大表述。
2. **应答预测模型的评价方式薄弱。** 跨队列外部验证样本量小、常以同一数据反复切分，且普遍不报告校准曲线、决策曲线与分层净获益。
3. **应答队列与耐药队列来自不同研究。** GSE78220 是治疗前活检，GSE244982 是 ICB 进展后活检（41 例）。多数研究直接把两者合并训练，掩盖了两者在生态位构成上的差异；把它们当作两个独立队列分别使用，反而能检验模型的适用边界。

## 四、科学问题与研究目标

**Q1（描述 + 比较）** 在同一份治疗中活检内，**肿瘤内在状态**（IFN-γ 应答程序、抗原呈递、增殖、EMT/迁移、缺氧、TNFα-NF-κB）与 T 细胞克隆性指标（克隆型数、top1 / top10 占比、克隆性指数、达 50% 所需克隆数）如何耦合？在不同治疗暴露时点（pre / on / post）与不同治疗方案下，这种耦合模式如何变化？哪些肿瘤内在状态与克隆性免疫识别的组合是耐药的伴随特征？

> **⚠️ 2026-10-07 更正（初稿写错，已在《终点口径与分析预登记》第十一节同步）**：初稿把「耗竭程度、驻留样表型」写进**肿瘤恶性细胞**的状态谱。这两个是 **T 细胞**状态，而 GSE308434 的 `cell type` 为 `tumor cell (nuclei)`、42/42 全部，肿瘤核里不存在 T 细胞，对肿瘤核打这两个分必然得到噪声。已改为肿瘤内在可测状态；免疫侧（耗竭、克隆性）由 GSE308435 的 TCR 指标承担。
>
> 同样更正：初稿写 TCR 侧有「克隆共享度、克隆型—细胞状态耦合强度」。**公开文件不支持**：每个文库是独立 TCR 序列库，无跨文库的克隆型共享信息，也无 TCR 克隆型 × 细胞状态的联合标注。已收敛为**文库内可算的 5 个克隆性指标**。

> **Q1 的边界（2026-10-06 核对后收紧）**：数据来源 GSE308433/434/435 只有肿瘤核与 TCR，**无应答标签**，且 34 例中仅 7 例有多活检。因此 Q1 只能回答"耐药形成的分子伴随特征是什么"，**不能回答"耐药发生在哪个时间窗"或"应答与进展的生态位差异是什么"**。后者须改由 GSE91061（nivolumab，带 Pre/On 配对与完整疗效标签）与 GSE244982（进展后）承担。

**Q2（预测）** 用单细胞定义、并可通过去卷积在常规转录组中估计的少量特征，能否在独立 bulk ICB 队列中比"IFN-γ 签名 / CD8 浸润 / CD274 表达"这类转录组基线更好地区分应答与进展？

**Q3（适用边界）** 该特征集在已经进展的样本上表现如何？哪些细胞状态在进展后被保留、哪些被替换？

目标强度限定为"关联刻画 + 预测可行性"，不外推到可直接改变用药决策。

## 六、技术路线

### 模块 1 数据获取与质控

下载表达矩阵与临床注释，建立统一基因命名与样本—患者映射表。质控参数（最小基因数、线粒体比例上限）依据各队列自身分布设定，不套用其他队列的经验阈值。配对活检以**患者**为分析单位，重复活检进入配对或混合模型，不把活检当独立样本。

**两处执行层陷阱（2026-10-07 记录，写进方法以保证可复现）**：

1. **基因注释体系各不相同**：GSE91061 的矩阵首列是 **Entrez Gene ID**（`min=1`、`max=101 559 451`，易被误读成行号）而 GEO 未随附注释表；GSE78220 与 GSE244982 是作者给基因名；GSE294272 是 GENCODE v7 的 `gene_name`。统一走 Entrez→HGNC 映射（`resources/Homo_sapiens.gene_info.gz`）后，**四个队列 × 六个主签名的基因覆盖率最低 95.5%、无一低于 90%**，说明四套注释体系最终能对齐到同一套符号。**特征可及性核查必须放在建模之前**，否则会出现"先建模型、再发现某队列某几个基因全是空值"的返工。
2. **样本列名体系各不相同**（`Pt1_Pre_AD101148-6` / `Pt1.baseline` / `HM002` / `Pat5`）：矩阵列一律改写为 **GSM 号**，原始列名另存 `meta/<cohort>_expr_columns.tsv`，下游脚本按 GSM 与患者级表对接，不再为特例写分支。四队列共 207 个样本列**无一列落空**。

### 模块 2 肿瘤内在状态 × TCR 克隆型的同活检配对刻画（Q1）

**数据基础（2026-10-06 回原文核对后确定）**：GSE308433 / GSE308434 / GSE308435 是同一研究的三个姊妹系列，来自 Columbia Izar 组，对应工作 *"Tumor-intrinsic **and extrinsic** immune mechanisms define resistance to immune checkpoint blockade in metastatic melanoma"*，投稿于 2025-09、公开于 2026-09-28，**截至核对日尚无论文发表**（Crossref、Europe PMC、bioRxiv、dbGaP、CELLxGENE 均查无）。

三个约束决定了本模块的设计，**不再沿用初稿"在 GSE308434 中按应答/稳定/进展三类比较"的写法**：

1. GSE308434 全部为 **肿瘤细胞核**，不含免疫细胞 → 做不了免疫生态位比例刻画；
2. **无 response / RECIST / 结局字段**（SOFT 全字段确认，三个姊妹系列皆然）→ 任何按应答分组的比较都不成立；
3. **42 份活检来自 34 例，其中仅 7 例有多活检**（F01、F02、F03、F12、F16、R310、R319）→ "42 份纵向样本"不是 42 条配对时序，全队列合并的 pre-vs-post 对比无效。

**改为的设计（2026-10-07 修订）**：以 **GSE308434 与 GSE308435 的 42 个文库一一对应**为基础，在**同一份活检内**把恶性细胞核的状态谱（IFN-γ 应答、抗原呈递、增殖、EMT/迁移、缺氧、TNFα-NF-κB，均以 MSigDB Hallmark 注释集打分）与 TCR 侧的文库内克隆性指标（克隆型数、top1 / top10 占比、克隆性指数、达 50% 所需克隆数）配对起来，检验耐药相关的肿瘤内在状态是否伴随克隆性免疫识别特征的改变。

> **为什么不用手写基因列表**：初稿写"耗竭、驻留样/TCF1 程序"这类自定义签名，须主观挑基因、口径不可复现。已改为 MSigDB Hallmark 注释集打分（抗原呈递用 `HALLMARK_ALLOGRAFT_REJECTION` 作代理，因 MSigDB v7 起下架了 `HALLMARK_ANTIGEN_PROCESSING_AND_PRESENTATION`）。

> **统计效力的硬约束（必须写进方案）**：42 个 TCR 文库中 T 细胞数**中位仅 148**、最小 2；按预先锁定的 **≥200 个 T 细胞**过滤后**只剩 18 个文库**可做配对。主比较因此只有 n=18，**结论只能作描述性，不得声称关联显著**。此前"42 个文库一一对应"的表述未提过滤，会让人以为 n=42。

**GSE308433（lpWGS）已按用户 2026-10-07 确认纳入**，作基因剂量的正交证据，检验口径见《终点口径与分析预登记》第十四节：

- 覆盖 **39/42** 个文库，FACETS 共识段格式；
- **只能做到染色体臂级**：低深度 WGS 的段跨度远大于单基因，**禁止基因级拷贝数判定**；
- 主统计量基于 FACETS 的 `copy.number` 列而非事件名——本数据集把拷贝数 1 记作 `HETD`、0 记作 `HOMDEL`，**`LOSS` 在 39/39 样本中出现 0 次**，按事件名取负值会得到"只扩增、无缺失"的假象；
- 该系列**不含 FACETS purity 输出**，无法按肿瘤纯度分层。

**表述纪律**：本模块输出的是**耐药形成的分子伴随特征，不是应答预测**。所有对比按 `treatment`（10 种方案，含挽救与试验背景）与 `genotype` 分层；`pre/on/post` 是**治疗暴露轴不是结局轴**，`post` 位点本身已富集难治病例，不得当应答标签使用。7 例配对患者只做样本内前后对比的描述，不做组间推断。

**结论强度上限**：该研究尚未发表，其样本分组与处理细节无第三方可复核性；本模块的发现只能作为特征来源线索，不能单独支撑因果或预后结论。

### 模块 3 特征定义与可及性筛选（Q1 → Q2 的桥接）

以 **GSE294273 的单细胞状态谱（12 例供体）**为细胞类型参考谱，把模块 2 得到的特征映射为两类输入：一是细胞比例型特征（去卷积可得），二是少量基因型特征（需明确每类标志基因的来源与物种一致性）。去卷积方法选择以支持自定义参考谱为先（CIBERSORTx 或非负最小二乘回归），并报告参考谱来源和版本。**关键约束：只保留在常规 FFPE/NGS 工作流中可获得的特征**，无法从组织样本测得的量（如流式细胞术比例）不进入模型。

**GSE294272 的角色从"参考谱来源"改为"独立验证集"**，依据 2026-10-06 核对结论：29 个样本实为 **26 例独立患者**，去重后应答组仅 4–5 例，**按应答组分建参考谱在统计上不成立**；且这些是**含瘤整块淋巴结**（原文用 SPIAT 分 Tumour / Stroma），恶性细胞比例不可控。使用时必须先做三步患者级处理：

1. 合并或择一 `HM003-Large` / `HM003-Small`（同一患者同一天的**两个不同瘤灶**，非技术重复）；
2. 处理跨时点重复患者——**`Mel-TIL-026` 与 `HM026` 是同一患者**（补充数据原文：`MT026 (ICI-resistant) and HM026 (ICI-responder) samples belong to the same patient, but collected at different times`），该对直接污染 Responder vs Resistant 对比，必须只保留一个时点或整例剔除；`Mel-TIL-019` / `HM019` 同理；
3. 预处理沿用原文口径：TMM 归一化后经 `limma::removeBatchEffect`。

`Mel-TIL-###` 是 2013–2015 年手术的**更早一批患者**（对应补充表 `MT###` 与 2018 年同实验室论文的 `MelTIL###`），与 HM 系列（2019–2022）不是同一批，不可与 HM 编号混用为同一患者轴。

### 模块 4 应答判别模型开发（Q2）

- 主终点：应答 vs 进展（二分类）。**标签口径已锁定**：GSE91061 的 `response` 字段是 Riaz 2017 的 **RECIST v1.1 最佳总体疗效（BOR）**，其中 `PRCR = CR + PR` 合并，`UNK` 4 例对应原文 `NE`。主分析用「PRCR vs PD」，SD 单列并做敏感性分析；执行前在《终点口径》文件中预登记。
  > **⚠️ 样本数不是例数（2026-10-07 更正）**：CR 7 + PR 16 = **23 是样本数，不是患者数**。按患者去重后 **PRCR 只有 14 例**（PD 29 例、SD 19 例、NE 3 例，合计 65 例）。写成"23 例"会把主终点阳性类规模夸大 **64%**，直接误导样本量与检验效能判断。患者级纳排表 `meta/patient_level.tsv` 是唯一权威来源，**所有样本量表述一律从患者级表取数，不得从样本表加总**。
- 开发：GSE91061，嵌套交叉验证；特征筛选、标准化、插补与调参全部在训练折内完成。**分析单位为患者**，且必须区分两个不同的集合：
  - **主分析患者级全集 43 例**（PRCR 14 / PD 29；SD 19 例与 NE 3 例不进主分析）——这是**终点口径**的集合。
  - **主建模集 33 例**（PRCR **10** / PD 23）——43 例中只有 33 例有**治疗前**样本，而临床决策点是「给药前判断谁应答」，故只有这 33 例可用于建模（口径锁定见《预登记》第十五节，锁定早于任何建模结果）。
  - 缺治疗前的 10 例为 Pt13/32/35/68/69/80/81/93/105/109。
  - GSE91061 的 Pre/On 是**同一病灶**的配对活检（Pre 为首剂前 1–7 天，On 为 C1D29），不得当独立样本计数。
  > **两级事实都必须出现在方案正文里**，不能只放在内部文档：主分析阳性类只有 **14 例**，而真正用于建模的阳性类只有 **10 例**。特征数需受硬上限 **≤10**（约每例阳性 1 个特征）约束，否则 AUC 必然虚高。
- **开发队列的三个已知混杂，建模时必须处理并记录**：① 既往免疫治疗——`NIV3-PROG` 59 样本 / `NIV3-NAIVE` 48 样本，该字段 GEO 未收录，从 Riaz 作者样本表回填（见 `meta/GSE91061_Riaz2017_sample_mapping.tsv`）；② `Pt109_On` 有两个分装样本（`AE527955-5` 与 `-6`），须合并或择一；③ `Pt68_On_AD635729-6` 在作者表中登记为 `Pt7_Pre_AD635729-6`，同一管号归属冲突，**以 GEO 标题为准并单独记录**。
- 冻结后在 GSE78220 外部验证（抗 PD-1 单药、不同中心）。**验证集口径以核对结论为准**：28 样本 / 27 例患者，其中治疗前 **27 样本 / 26 例患者**（CR 4 / PR 10 / PD 12）；**`Pt16` 只有 on-treatment 样本**，须显式说明或做剔除敏感性分析。`Pt27` 的 `Pt27A` / `Pt27B` 是同患者治疗前**两个不同解剖部位**（右臂 / 右上背）的活检，按患者内重复处理，不得当技术重复平均。
- 评价三件套：AUC（含 DeLong 检验）、校准曲线与 Brier 指数、决策曲线与分层净获益。
- **强制基线：IMPRES**（Auslander et al., Nat Med 2018，PMID 30127394）。该评分由 15 对免疫检查点基因的转录组两两关系构成。**基线理由（2026-10-06 更正）**：IMPRES 的特征筛选训练于**神经母细胞瘤**自发消退数据，其**开发队列是 GSE115821**（MGH 队列，31 例抗 PD-1 + 10 例抗 CTLA-4），**GSE91061 是它的验证队列之一**（该文参考文献 6），不是开发队列。仍列为强制基线的理由是：它是已发表的同类 SOTA 预测器，且已在 GSE91061 上被报告过性能（该文跨数据集 AUC 0.77–0.96），不同场比较才能说明新模型是否增加了信息。**引用时不得写"它是在本队列上开发出来的"**。
- 其余转录组基线：IFN-γ 应答签名、TIDE 分数、CD8 浸润估计、CD274 表达。仅以转录组可得基线为对照，不声称优于 PD-L1 免疫组化（GEO 队列通常不含 IHC 状态）。
- 队列间表述用"**跨队列、跨中心、跨抗 PD-1 药物**验证"：GSE91061 为 nivolumab 3 mg/kg q2w **单药**（CA209-038 / NCT01621490），GSE78220 为 pembrolizumab **或** nivolumab 单药（原文口径；GEO 全部标 pembrolizumab 属简化），**两者均非联合用药队列**。不使用"抗 PD-1 与抗 CTLA-4 混合队列"的表述。
- 同时报告不确定度（自助法置信区间），避免只给单点 AUC。

### 模块 5 适用边界检验（Q3）

在 GSE244982 上计算同一冻结模型的分数，比较其在"已进展"样本中的分布，并检验模块 2 识别的耐药相关特征在进展样本中是否复现。若模型在进展样本中同样给出高"应答"分，说明特征捕捉的是免疫浸润强度而非耐药状态，必须如实报告并调整结论强度，而不是更换验证集。

**该队列的四个已核实约束（2026-10-06 核对）**，使用前必须处理：

1. **全部 41 例均为 ICB 进展后取样**（原文："all biopsies from metastases were taken after progression"），因此本模块只能检验"模型是否在耐药样本上给出预期的低分"，**不能声称验证了区分能力**。
2. **`prior.ctla4i` 标记为不可用**：该字段 37/41 为 TRUE，但语义是"曾暴露于 CTLA-4i"的并集——anti-PD1 组为真既往进展，anti-CTLA4 组则是本次 index 治疗本身，与 `treatment` 结构性共线。若需既往用药信息，从作者 Source Data 逐患者重建并剔除 anti-CTLA4 组。
3. **11/41（27%）样本处于 BRAFi 联合暴露**（`previous.brafi = no_During, day 7`，即按试验方案先用 vemurafenib **第 7 天**取活检）。这是耐药态刻画的**强混杂**，必须按该字段分层或做剔除敏感性分析。
4. `groups` 实为 5 类：`anti-CTLA4 resistant` 17、`anti-PD1 resistant` 10、`anti-PD1 resistant, BRAFi day7` 10、`mucosal` 3、`NA` 1。`mucosa` 3 例原文已排除出统计，`NA` 1 例（Pat31）为漏填。

## 八、执行边界与风险

**不做的事**：不宣称模型可替代 PD-L1 检测或直接指导用药；不做生存外推当用药决策；不把基因集评分、细胞通讯或计算扰动写成机制已验证；不在同一数据上反复切分以抬高性能；不把细胞数当独立患者数。

**主要风险与对策**

| 风险 | 表现 | 对策 |
|---|---|---|
| 响应标签缺失或定义不一 | 队列无法用于判别建模 | 模块 1 先核对标签字段；标签不全的队列降级为描述性分析角色 |
| **既往免疫治疗混杂**（GSE91061） | `NIV3-PROG` 59 / `NIV3-NAIVE` 48 样本，特征可能在耐 ipi 人群中特异 | 从 Riaz 作者样本表回填该字段，作协变量并做分层敏感性分析 |
| **样本重复与编号冲突**（GSE91061） | `Pt109_On` 两个分装样本；`Pt68_On_AD635729-6` 与作者表 `Pt7_Pre` 同管号 | 合并/择一分装样本；以 GEO 标题为准并单独记录冲突样本 |
| **患者内活检重复**（GSE78220） | `Pt27A` / `Pt27B` 为同患者两个不同部位活检，当独立样本会低估方差 | 按患者做 group-aware 划分；另报"仅取 Pt27A"的敏感性分析 |
| **患者级泄漏**（GSE294272） | `Mel-TIL-026` 与 `HM026` 是同一患者却分属 resistant / responder | 合并或整例剔除；去重后 26 例独立患者 |
| **BRAFi 联合暴露**（GSE244982） | 11/41（27%）样本处于 BRAFi 第 7 天用药中 | 按 `previous.brafi` 分层并做剔除敏感性分析 |
| **参考研究尚未发表**（GSE308433/434/435） | 样本分组与处理细节无第三方可复核 | 模块 2 结论只作特征来源线索，不作因果或预后结论 |
| **TCR 文库普遍过小**（2026-10-07 新增） | 42 个文库 T 细胞中位仅 148、最小 2，按 ≥200 过滤后仅剩 **18 个文库** | n=18 只能作描述性，不声称关联显著；主比较 3 对事先指定，其余探索性做 BH-FDR |
| **lpWGS 分辨率不足**（2026-10-07 新增） | 低深度 WGS 段跨度远大于单基因，且不含 purity 输出 | 只做染色体臂级，禁止基因级拷贝数判定；无法按纯度分层，该限制写进结论 |
| **注释体系不一致**（2026-10-07 新增） | GSE91061 用 Entrez、其余队列用基因名；不一致会在打分阶段静默产出空值 | 建模前先跑特征可及性核查（四队列 × 六签名最低 95.5%）；矩阵列统一为 GSM |
| 队列间批次与瘤种混杂 | 特征看似区分队列实则区分瘤种 | 逐队列单独建模并报告特征-队列关联；跨队列只做一致性检验 |
| 特征在纵向数据中不稳定 | 单细胞结论无法迁移到 bulk | 模块 3 强制可及性筛选；不稳定特征提前丢弃并记录理由 |
| **主终点阳性类偏小**（2026-10-07 新增） | 主建模集仅 33 例、其中 PRCR 仅 10 例，特征数一多必过拟合 | 特征数按"每例患者不超过 1 个特征"量级约束；报告每折表现离散度；所有样本量表述从患者级表取数 |
| 跨队列合并诱惑 | 结果好看但不成立 | 在流程上禁止样本级合并，把差异当作研究对象 |

**如果标签字段核对失败**：退守为"肿瘤内在状态 × TCR 克隆型的同活检配对刻画 + 跨队列特征一致性"研究，仍可独立成篇，但结论强度相应下调，不硬造判别终点。

## 十、备选方向卡（皮肤镜影像方向）

主方案因标签字段或队列规模受阻时切换，或作为团队内第二条独立赛道。

**题目**：《跨域稳健的皮肤镜黑色素瘤判别系统：病灶级去重评估、校准迁移与拒识转诊规则》

**为什么不能按常规做法**：HAM10000 七分类训练与测试已是数年前的通行练习，增量只体现在换 backbone。真正影响临床可用性的三点是：同一病灶的多张图像被拆入训练与测试两侧导致性能虚高；不同来源图像（不同设备、不同采集条件）之间的性能衰减未被量化；模型在低把握时仍给出确定结论，而临床场景需要"拿不准就转诊"。

**可做的内容**

1. 病灶级（而非图像级）分组划分，明确同一病灶多图不跨集合。
2. 训练来源定阈值，在外部来源上评估该阈值的校准是否仍然成立。
3. 拒识机制：低置信度样本输出"需皮肤科面诊"而非强行分类，评价拒识率与漏诊率的交换曲线。
4. 与公开可得的读片者对照数据比较，回答"模型在哪一类病变上劣于或优于专科读片"。

**数据现状**（核验于 2026-10-06）

| 数据 | 状态 |
|---|---|
| ISIC Archive | 可用。API 实时统计公开皮肤镜图像 **553,019 张**，含诊断、部位、性别、年龄标注 |
| HAM10000 | 原始发布平台域名（researchdata.nyph.org）当前无法解析，需改用镜像渠道，编号与完整性待重新核验 |
| PAD-UFES-20 | 原 DOI 未在 DataCite 检到，需重新确认获取渠道 |
| BCN20000 | 未核验 |

**切换条件**：主方案在第 2 周标签核对失败，或团队有影像方向人员时启动。

## 十二、医工交叉落点

本方案为纯数据研究，医工属性体现在"输入可获取性 + 交付物形态 + 工作流位置"三处：

1. **输入可获取性**：模型只接受常规病理与检测流程中可得的信息（FFPE 组织转录组），不使用任何需要额外流式、空间或活检手段才能获得的量。
2. **交付物形态**：不是一张基因名单，而是冻结的评分卡（输入项、单位、阈值、缺失处理、输出解释），加上模型卡与可复现脚本，可直接接入分子病理报告系统。
3. **工作流位置与增量**：明确该评分是辅助分子病理分型信息，作用是在 PD-L1 免疫组化之外提供补充判断，并给出决策曲线说明在什么阈值区间有净获益。

**若赛事要求实物载体**（当前按纯数据设计，此处仅作条件性说明）：可增加低成本工程件，把评分卡与图像输入整合为桌面级采集/判读装置原型，例如皮肤镜成像模组加本地推理的小型计算单元。此路径需要额外时间与预算，不属于当前方案范围，需另行确认资源后再决定。
