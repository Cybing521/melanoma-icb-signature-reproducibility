# 图件风格仿制与参考文献扩充记录（2026-10-08）

> 起因：投稿前 review 提出两条意见——(1) 现图「过于一般」；(2) 参考文献 13 条偏少。
> 本文档记录**怎么做的**与**凭什么这么做的**，按本项目惯例「错误与改动一律留痕」。
> 关键原则：图件的字体与配色不是凭印象挑的，是从本文直接对照的原始文献里**量出来**的。

1. **PMC OA 接口迁移**。`https://www.ncbi.nlm.nih.gov/pmc/utils/oa/oa.fcgi` 已 404，

   HTML 挑战页而不是 PDF**——必须校验文件头 `%PDF` 再判定成功。

脚本：`refs/fetch_refs.py`（PDF 解析）、`refs/grab_figures.py`（图件原图）。

## 二、字体与配色的实测结果

`refs/probe_style.py` 做两件事，都只测量不判断：

* **字体**：PyMuPDF 只能给出子集名（如 `CPPJKO+AdvOT511ca30e.B`），故把嵌入字体
  文件取出、用 fontTools 读 name 表。三篇 *Nat Commun* / *NPJ* 的字体全是 CFF
  子集，family 名读不出来（脚本如实标 `(CFF subset)`）；**改由人工核读原图确认**，
  这些期刊的图件正文统一为 Arial/Helvetica 无衬线，字号 7–8 pt。这与 MDPI 要求的
  Arial 8–10 pt 一致，故字体沿用 Arial。
* **配色**：把每页栅格化后统计饱和度 >45 的彩色像素，按 16 级量化取众数簇。

### 据此定下的本稿配色

领域惯例在上述文献里是**一致的**：Hugo 用蓝=应答 / 红=不应答，Auslander 的 KM 曲线
用蓝=High IMPRES / 红=Low IMPRES。因此直接沿用这条惯例：

| 用途 | 取值 | 来源 |
|---|---|---|
| 签名 1 IMPRES | `#1F5FA9` 深蓝 | Lauss `#0060A0` 深色端 + Hugo 浅蓝的深色版 |
| 签名 2 IPS-MHC+CP | `#C8392F` 鲑红 | Auslander `#FC6060` / Riaz `#F06C6C` 深色端 |
| 浅色伴生色 | `#A8CBE8` / `#F0A9A0` | Hugo `#90CCFC` / `#FCB4B4` |
| 已排除 / 通过 | `#2E7D5B` 绿 | Lauss `#70B020`、Riaz 青 `#249084` 深色端 |

**与初版的最大差别**：初版两个签名用蓝 `#0072B2` + 橙 `#D55E00`（Okabe-Ito 色盲安全
配色）。安全配色没错，但它**不是这个领域的视觉语言**，读者扫一眼认不出哪个是应答。
改成领域惯用的蓝/红后，语义不需要图注解释。

## 三、面板标号保持 MDPI 体例，没有改成大写 A.

参考文献（*Nat Commun* / *Cell*）用大写 `A.`、`B.`；初版一度想照抄。**最终没有改**，
理由：投稿目标是 MDPI *Cancers*，其作者指南要求面板标号用小写加粗括号 `(a)`。
版式模仿的收益集中在配色、字号、留白与信息层次上，面板标号大小写收益极小，
却会直接违反投稿体例。**记录此决策，以免日后误以为漏改。**

### 两个实测数据坑

1. **JCI 的 `ELocationID pii` 不是页码**。PMID 28650338（JCI 2017）若优先取 ELocationID
   会得到 `91190`（取自 JCI91190 这个文章号），正确页码是 MedlinePgn 的 `2930-2940`。
   脚本已改为**只在 MedlinePgn 为空时才用 ELocationID**。
2. **PubMed 的 DOI 字段有错配**。PMID 31519915（Griss, *Nat Commun*）的 PubMed DOI 指向
   一篇无关的 *Nucleic Acids Res* 文献，正确 DOI 是 `10.1038/s41467-019-12160-2`。
   同类错配还见于 30635339、16504092、29531091、28650338。**DOI 一律以 Europe PMC 为准。**

### 编号重排：为什么必须脚本做

MDPI 要求参考文献**按正文首次出现顺序编号**。新增引用会把后面全部条目挤动，
手工维护极易出错（`1→2、2→3` 级联错位）。因此编号由
`manuscript/build_manuscript.py` 的 `apply_citation_edits()` 自动分配：
先按占位符 `[[Nk]]` 插入措辞，再扫描首次出现顺序**一次性同步替换**。

> 实测踩坑：第一版把终稿编号（`[15]`、`[24]` 等）**直接写进措辞**，重编号时这些乱序
> token 被当成新的首次出现，整张映射错位，25 条被压成 20 个编号。改为占位符后复现正常。
> **教训：插入用占位符，编号交给脚本，两者不可混用。**

### 一处未能补上的缺口（如实记录）

多次定向检索后，**未找到可核实的「黑色素瘤签名外部验证失败」的原始研究论文**：
LINS/TCIA（Natarajan 2019）与 MPscore（Bessell）在 PubMed 均检不到可核实记录，
故**不予引用**，也不追认其存在。因此「分类 B」由肿瘤学界通用的验证失败文献
（Steyerberg 2010、Ioannidis 2008）承担，而非黑色素瘤专属的复现失败论文。
**这是一个真实缺口，审稿人可能会问。**
