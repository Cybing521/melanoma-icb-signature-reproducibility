# 第二个签名 `IPS-MHC+CP` 的三队列验证

> 口径锁定于 `docs/03` §22，**写于任何计算之前**。生成脚本 `scripts/23_ips_mhccp.py`。
> 本文件与 `docs/07`（IMPRES）互为对照，两者结论必须一起读。


## 一、一句话结论

**按预登记 §17.4 的判定标准，三个队列、两个方向全部未复现**（CI 均覆盖 0.50，点估计均不在 0.70–1.00）。

**但它与 IMPRES 的失败方式不同，而且这个差别必须写清楚**：三个队列的高分方向 AUC 分别为 **0.604 / 0.583 / 0.591**——**方向一致、全部高于 0.50**，且基因覆盖 20/20、标签与队列口径完全一致。IMPRES 则没有任何一致方向。

这是一个**弱而方向一致的信号**，不是噪声。它不满足本项目的复现门槛，因此**不作为阳性结论报告**；但它同样**不能被并入"全部是随机"那一栏**，因为两者不是一回事。

---

## 二、选定过程：一次必须记录的获取失败

目标是 Immunophenoscore（IPS，Charoentong et al., Cell Rep 2017, PMID 28052254）——领域内与 IMPRES 并列被引用最多的 ICB 应答预测器。**选它的判据在 `docs/03` §22.1 写定于计算之前**，核心是：构造原理必须与 IMPRES 不同（IPS 是 26 个免疫特征集的加权 z 分数，IMPRES 是两两大小排序）、来源团队独立、黑色素瘤/ICB 相关。

**完整 26 个特征集的基因表无法从任何开放来源取得**，6 条路径全部失败：

| 路径 | 结果 |
|---|---|
| Cell Reports 全文页直取 | HTTP 403 |
| ScienceDirect API | 连接失败 |
| TIDE 官方 GitHub（两个可能路径） | 仓库 Not Found |
| CRAN `tide` 包 | HTTP 404 |
| GitHub 代码搜索 `hack_immunophenoscore` | 需认证 |
| Europe PMC `PMC5624513` 全文 | 返回非本文内容 |

> **这本身就是论文要写的一条发现**：领域内排名第 2 的 ICB 应答签名，其完整基因表无法从任何开放来源重建——与 IMPRES 遇到的是同一堵墙。**"已发表签名不可复现"不只是性能问题，也包括可获取性问题。**

改测 `IPS-MHC+CP`：IPS 四个类别中**只有 MHC 与 CP 两类在开放文献中被逐基因完整列出**，共 20 个基因，构成本项目的检验对象。

---

## 三、结果

| 队列 | n（PRCR/PD） | 基因覆盖 | 高分方向 AUC | 95% CI | 单侧 p | 镜像方向 |
|---|---|---|---:|---|---:|---:|
| GSE91061 | 33（10/23） | 20/20 | 0.604 | 0.365–0.822 | 0.179 | 0.396 |
| GSE78220 | 26（14/12） | 20/20 | 0.583 | 0.339–0.821 | 0.244 | 0.417 |
| GSE215868 | 79（45/34） | 20/20 | **0.591** | **0.463–0.714** | 0.085 | 0.409 |

**判定（§17.4 写死的标准）：三队列均未复现。** CI 下界均 ≤ 0.50，点估计均在 0.70–1.00 之外。

样本量最大的 GSE215868 是最有说服力的一支：n=79、CI 宽度仅 0.25、p=0.085——**既不足以宣称有效，也不足以排除一个中等效应**。

---

## 四、这个结果与 IMPRES 的关键差别

| | IMPRES | `IPS-MHC+CP` |
|---|---|---|
| 构造原理 | 免疫检查点基因**两两大小关系** | 抗原呈递 + 检查点基因的**加权 z 分数** |
| 基因数 | 15 | 20 |
| 常规临床面板覆盖 | 13/15（86.7%） | **20/20（100%）** |
| 基因表可开放获取 | **否**（从作者 GitHub 重建） | **是**（开放文献逐基因列出） |
| 三队列 AUC | 0.359 / 0.298 / 0.505 | **0.604 / 0.583 / 0.591** |
| 方向是否一致 | **否**（0.36、0.30、0.51，无规律） | **是**（三个队列同向，且均 > 0.50） |

**这张表是全文最有价值的对照，理由有三：**

1. **两个构造原理完全不同的签名，得到两种不同的失败方式。** IMPRES 是彻底的方向混乱；`IPS-MHC+CP` 是稳定的弱正向。这说明「阴性」不是一个笼统结论，而是**按签名构造而异**。
2. **`IPS-MHC+CP` 失败时无法用任何技术性辩解搪塞过去**：基因表是公开的、面板覆盖 100%、三个队列标签口径一致、n 最大的一支有 79 例。它不满足门槛，是因为**效应量小**，不是因为测不准或样本不够。
3. **因此本文能给出一个有建设性的结论**，而不只是"什么都没发现"。

---

## 五、建设性结论：这个信号需要多大的样本？

可以诚实地说的是：**三个队列一致指向一个约 0.59 的弱效应，它没有被证实，也没有被排除。**

把它当作定量的观察（不是检验结果）：

| 若真实 AUC 为 | GSE215868（n=79）观察到的 95% CI 大致覆盖 | 判定 |
|---|---|---|
| 0.50（无效应） | 是 | 不可拒绝 |
| 0.59（本项目观察值） | 是 | 不可拒绝 |
| 0.70（原文级别） | **否——CI 上界仅 0.714，几乎贴边** | 基本可排除 |
| 0.77（IMPRES 原文下界） | 否 | 可排除 |

**所以能说的是**：在 n=79 这一支队列上，可以**排除 0.70 及以上**，但**无法区分"没有效应"与"存在约 0.59 的弱效应"**。要确认后者，需要的样本量远超本项目能拿到的任何一个队列。

> **必须写明这不是新检验。** 上表是对三个已算出的 AUC 及其 CI 的描述性解读，**不是**在结果出来后新增的合并分析或假设检验。项目没有、也不打算为此另做一次合并检验——那正是预登记禁止的事。

---

## 六、结论的边界

1. **`IPS-MHC+CP` 不是 IPS。** IPS 的 `EC`（效应细胞，4 个特征集约 100 基因）与 `SC`（抑制细胞，2 个特征集 40 基因）两类的基因表无法开放取得，本测试**未覆盖 IPS 的全部四个类别**。任何时候都不得把本结果写成"IPS 未复现"。
2. **z-score 是队列内相对量**，不是绝对表达量——这是 IPS 构造自带的限制，不影响队列内 PRCR vs PD 的判别检验。
3. **用的是连续 raw 分数**，不是 IPS 原文的 0–10 整数离散化（预登记 §22.5 事先判定该离散化会摧毁 n=45 量级的排序分辨率）。
4. **未消除 IMPRES 的残余风险。** 本项目的 IMPRES 实现本身是从作者 GitHub 重建的，这是所有 IMPRES 相关结论最主要的可攻击点。第二个签名补的是**「已发表签名系统性不可复现」**这一更宽的论断，**不能**替 IMPRES 的实现正确性背书。
5. **弱信号不得被写成阳性结论。** 预登记的门槛就是门槛；本文报告的是「未复现，但方向一致」，不是「部分复现」。

---

## 七、对论文主线的影响

主线从「六条证据链全部阴性」升级为一条更准确、也更有建设性的论断：

> 在**两个构造原理不同、来源独立**的已发表 ICB 应答签名上，本项目的独立验证都**没有复现已发表的性能**。但失败方式并不相同：其中一个完全无规律，另一个则**在三个独立队列上给出方向一致的弱信号（约 0.59）**，且该签名在临床可及性上完全达标。这提示该领域公开签名中可能存在**尚未被证实、也尚未被排除的小效应**，其验证所需的样本量远超当前公开数据的规模——这本身是一条对领域有意义的、可检验的命题。
