## 七、评价指标（主分析固定）

| 项 | 指标 |
|---|---|

**细胞核过滤阈值（锁定）**：

| 阈值 | 取值 | 依据 |
|---|---|---|

三项均为**宽松阈值**，单核 RNA 数据的 RNA 含量本就低于单细胞，套用 scRNA 的阈值会把大部分真实核切掉。预期合计剔除 10–15% 的核。

> **2026-10-07 实跑结果与该预期不符，如实记录**：42 样本全量质控跑完后，阈值实际只剔除了 **2.41%** 的核（346 102 → 337 763，样本级留存 81.5%–100%），远低于预期剔除 10–15%。原因是对照上表分位数可查：全队列 `umi_p05` 实际为 540–2357、`feat_p05` 为 350–1568，**绝大多数核本就高于阈值**，阈值切的是极窄的尾部。
>
> **阈值不予调整**。它们是在看到任何结果之前按"宽松、避免切掉真实核"的依据锁定的，看到留存率偏低后再收紧就是结果导向的阈值调整。改为把该事实记入限制：质控在本次分析中几乎不起作用，低质量核主要靠后续签名的分布形状量（`*_sd` 等）而非核级过滤来抑制影响。
>
> 另记一个下游风险：核数最少的样本是 `GSM9245420_F23_post`（原始仅 706 核，`mt_p95` 高达 44.6%），其次 `F27_post1_pre2`（2259）、`F07_post1_pre2`（2689）。质控后留存核过少的样本其签名离散度估计不稳定，读结果时须逐样本看 `n_nuclei_qc`，不得只看整体相关性。**同样不为它们单独设阈值**。

### 11.3 两点必须记录的基因集限制

1. **抗原呈递用的是代理集**。MSigDB 自 v7 起下架了 `HALLMARK_ANTIGEN_PROCESSING_AND_PRESENTATION`，Hallmark 2024.1.0 中不存在。改用 `HALLMARK_ALLOGRAFT_REJECTION`——它是 Hallmark 里唯一携带完整 MHC/TAP 机器的集合（B2M、HLA-A/E/G、CD74、HLA-DR/DM/DO/QA、TAP1/2、PSMB10、TAPBP）。
2. **抗原呈递与 IFN-γ 应答高度共线**，因为 ALLOGRAFT_REJECTION 本身被 IFN-γ 通路强烈驱动。**两者不可当作彼此独立的证据**。

### 11.4 打分方法与一个被剔除的统计量

CP10K 归一化 + log1p → 每个样本内按基因做 z-score → 签名内取均值。

**样本级均值 `*_mean` 在数学上恒等于 0**（基因在样本内 z-score 后均值为 0，签名内取均值再对核求均值仍为 0），不含任何信息，已从输出中剔除。改用三个分布形状统计量：

| 统计量 | 含义 |
|---|---|
| `*_sd` | 样本内状态分离散度（该活检肿瘤群体的状态异质性） |
| `*_p90_p10` | 90 分位减 10 分位的跨度（对离群核稳健的分布宽度） |
| `*_hi_pct` | 得分高于「本样本均值 + 0.5 SD」的核占比（高状态核比例） |

三者都是**样本内相对量**。因此本模块可回答的是「状态构成 / 异质性如何随治疗暴露与 TCR 克隆性变化」，**不回答也不应被解读为状态的绝对表达水平**。

### 11.5 主比较（事先指定，不做挑选）

仅 3 对进入主要结论，用 Spearman 秩相关：

1. IFN-γ 应答 × 克隆性
2. 抗原呈递 × 克隆性
3. EMT × 克隆性

其余全部为探索性并做 BH-FDR 校正，**不得用于支持主要结论**。不因不显著而更换指标、阈值或改用配对子集重跑。

### 13.1 一处必须记录的数据坑：GSE91061 的行名是 Entrez Gene ID

GEO 补充目录只有 4 个文件（fpkm / raw / rld / cytolytic score），**没有随附基因注释表**。首次查看 `raw.csv.gz` 时首列为空、取值形如 `1, 10, 100`，容易被误读成行号。实测：

| 项 | 值 |
|---|---|
| 唯一值数 | 22 187 |
| 最小 / 最大 | 1 / 101 559 451 |
| 均值 | 7.35 × 10⁶ |

行号不可能取到 101 559 451，因此首列是 **Entrez Gene ID**。已用 NCBI `Homo_sapiens.gene_info`（`resources/Homo_sapiens.gene_info.gz`，tax_id 9606）映射到 HGNC 官方符号：

- 映射率 **98.43%**（21 838 / 22 187）；未命中的 349 个记在 `meta/GSE91061_symbol_map.tsv`，原因是 `no_symbol_in_gene_info` 或 `duplicate_symbol_dropped`（同一符号对应多个 Entrez 行，取首个）。
- 抽样校验：`A1BG` 行数值（436, 562, 306, 228, 279, 251, 1124, 661 …）与原始第 1 行完全一致，映射方向正确。
- 丢弃 `Symbol` 为 `-` 的占位行（349 条中的多数），否则这些行会以无效符号进入矩阵。

> 若不发现这一点，后续所有签名打分都会因为找不到基因而全空；而这件事只有在做特征可及性核查时才暴露。

### 14.1 纳入理由与它回答什么问题

模块 2 的状态分来自表达。表达升高的原因可能来自**拷贝数增加（剂量驱动）**，也可能来自**转录调控（表达驱动）**。GSE308433 提供低深度 WGS 的拷贝数分段，可把两者分开：

> **同一签名的高表达状态，是否伴随该签名基因所在区域的拷贝数改变？**

- 若相关 → 该程序是**剂量驱动**的，提示可干预的是基因组状态而非表观调控；
- 若不相关 → 该程序是**调控驱动**的，更可能存在可逆的上游开关。

这是正交证据，不参与任何预测模型的构建，**只用于解释模块 2 观察到的状态差异从哪来**。

### 14.3 统计量的定义（锁定）

**主统计量：染色体臂级拷贝数失衡 `cn_arm`**

```
cn_arm(arm) = Σ_segments[(CN - 2) × 段长] / Σ 段长        （相对二倍体 CN=2）
```

> **2026-10-07 方法更正（在看到任何关联结果之前）**：本节初稿写作
> `cn_arm = (GAIN 覆盖 bp − LOSS 覆盖 bp) / 该臂覆盖 bp`，用 FACETS 的**事件字符串**做分子。
> 实现并首次跑通后立刻发现该定义失效——本数据集 **39/39 样本的 `LOSS` 事件数为 0**，
> 因为 FACETS 把拷贝数 1 的段记作 `HETD`（杂合缺失）而非 `LOSS`，把拷贝数 0 记作 `HOMDEL`；
> 按事件名取负值会得到"只扩增、无缺失"的假象（实测 0/39 样本有任何臂缺失）。
> 同一批 FACETS 判定本身是正常的：33/39 样本的众数拷贝数为 2，中性段占基因组 60%（中位），
> 扩增段占 19.7%（中位）、高幅扩增 3.7%。
>
> 故改为直接使用 `copy.number` 列而非事件字符串——CN 是 FACETS 的原始判定，
> 事件名只是它的符号约定，换一个约定不会改变数据本身。事件名的 bp 占比保留为质控输出。
> **这次更正不涉及任何结果驱动的选择**：跑通时状态分只完成 2/42，三项主比较一个都还算不出来。

用 CN 而非事件名的另一层理由：CN 是相对二倍体的**剂量**定义，量纲统一、可跨样本比较；
事件名还隐含了对亚克隆性的处理，跨样本一致性不如 CN 直接。

**臂的定义**：采用 GRCh37 标准细胞遗传学臂界（1–22 号染色体 p/q），为公开参考常量，不做主观划分。**X、Y、MT 一律排除**在主分析之外（避免 X 拷贝数与性别、纯度估计纠缠）。

**签名剂量分 `cn_dosage_X`**

```
cn_dosage_X = median{ cn_arm(arm) : arm ∈ 该签名基因所占的不同臂 }
```

**按不同臂取中位数而非按基因取**——同一臂上的多个基因不是独立观测，按基因取会把一个臂的信息重复计入、虚增有效样本量。

**全局 CNA 负担 `cna_burden`**

```
cna_burden = |CN - 2| ≥ 1 的段覆盖 bp / 全常染色体覆盖 bp
```

**质控附带输出**：每文库的**众数拷贝数**。5/39 样本众数为 3（近三倍体），其全基因组剂量会被计为升高——这是真实的三倍体状态而非伪影，但读结果时须先看该列。

### 14.4 必须如实记录的限制

1. **无纯度值**：低肿瘤含量样本的 CN 幅度被压缩，**无法按纯度分层**。CN=1 的段在纯度低时会被 FACETS 判成 `NEUT` 而非 `HETD`，臂级缺失程度因此被系统性低估；该偏差方向对所有样本一致，不影响组间比较，但**绝对拷贝数的可信度低于相对比较**。
2. **lpWGS 分辨率**：无法判定基因级事件。臂级口径已是最细的可辩护粒度。
3. **39 例样本、单序列、无配对 CNV**：不构成机制证据，只作伴随性描述。
4. **倍性混杂**：5/39 样本的众数拷贝数为 3（近三倍体）。整臂 CN-2 剂量会把全基因组升高一并计入，故须同时读 `modal_cn` 列判断信号是局灶事件还是倍性漂移。
5. **多比较**：主比较 3 对固定，探索性另做 BH-FDR，两者不得混用。

1. **不需要为本队列挑选归一化方法**，因为选择不存在。主分析直接用 NanoString 原始计数。
2. 若原文作者用的是别的归一化（多数 ICB 免疫文献用 quantile / z-score / voom），**其 IMPRES 数值与本实现应当逐样本相同**。故"归一化方式不同"**不能**被用作本实现与原文不一致的解释。
3. 因此本节刻意安排一项**实现校验**：对同一批样本分别用原始计数、文库大小归一化、内参中位数归一化、`log2(x+1)` 计算，要求 105 个样本的分数**完全逐样本相等**。不相等即说明实现有 bug，先修 bug 再谈结果。

**「能否复现原文性能」的判定规则事先写死：**

1. **复现**：某方向的 95% CI **下界 > 0.50**，且其 AUC 点估计落在 **0.70–1.00**。满足者即判为作者实际用法。
2. **未复现**：某方向的 CI 覆盖 0.50。
3. **两向皆未复现**：判为「本实现无法复现原文报告的性能」，并且——
   > **不得**据本队列的结果反向指定方向、调整基因对或修改公式。

## 十九、单细胞簇指派的客观 tie-break 规则（2026-10-07 锁定，**在 tie-break 结果产生之前写定**）

### 19.1 为什么必须解决

`scripts/13` 已跑通质控（88 715 → 85 167 细胞，剔除 4.0%）、HVG、PCA、Leiden 41 簇，指派用 `sc.tl.score_genes` 的簇均值取 `argmax`。该法的弱点是**打分是表达量纲的绝对值**，容易被少数高表达基因拉偏，实测有 **6 个簇 margin < 0.3**：

| 簇 | 现指派 | margin | 问题 |
|---|---|---:|---|
| 5 | T_CD8 | 0.030 | 与次高几乎持平 |
| 9 | T_CD8 | 0.035 | 实际为 NK（`METRNL`/`CCL5`/`GZMB`），**导致 NK 被并入 CD8 T** |
| 12 | Melanocyte | 0.276 | 模糊 |
| 24 | T_CD8 | 0.254 | 模糊 |
| 34 | Melanocyte | 0.105 | 实际为成纤维细胞（`COL6A1`/`COL4A2`/`POSTN`），**导致参考谱完全缺失 Fibroblast** |
| 38 | Melanocyte | 0.242 | 模糊 |

簇 9 与簇 34 是硬伤：**Fibroblast 在整个参考谱中计数为 0**。去卷积时该类表达会被错误归到邻近谱，参考谱即失真。

### 19.2 tie-break 规则（锁定）

**主判据改为富集检验，而非打分绝对值**：

1. 对每个簇，取其 **top-30 差异表达基因**（Wilcoxon，`scripts/13` 已产出 `qc/scrna_cluster_markers.tsv`，此处不重算排序）。
2. 对每个候选细胞类型，取其在 `MARKERS` 中**且确实被检测到**的基因集，与该簇 top-30 求交集。
3. 计算**单侧超几何富集 p 值**：零假设为"该簇 top-30 与该类型 marker 集独立"，总体取"被检测到的基因全集"。
4. **指派规则**：取 p 值最小者；若最小 p > 0.05（无任何类型显著富集），该簇标记为 **`Unassigned`，不计入参考谱**，并从去卷积的分母中剔除。
5. 并列（p 值相同）时，以**交集基因数**为次序；再并列时，以 `scripts/13` 的 `score_genes` 取值次序。

### 19.3 为什么不直接按人工判读指定簇 9 与簇 34

按 top markers 人工指定虽然也能改对，但那是一次**看结果后的人工选择**，无法在其他人身上复现，且无法界定"多模糊才算模糊"。富集检验有明确的零假设、明确的显著性阈值和明确的弃权规则（`Unassigned`），可被第三方重跑复现。

### 19.4 事后仍必须记录的

- 富集检验只解决**指派**，不改变聚类本身。41 簇的分辨率是 2026-10-07 早于本节写定的，**不因指派结果回头改分辨率**。
- 被判为 `Unassigned` 的簇，其细胞在去卷积时按"未知组分"处理，**不得就近指派**。
- 本节只影响**去卷积参考谱**。模块 2（肿瘤内在状态打分）与模块 2b（基因剂量）**不使用细胞类型指派**，其结果不因本节改变。

## 二十三、功效分析与跨队列 AUC 元分析（2026-10-07，**计算前写定**）

### 23.3 预登记与 §3 的一致性（关键）

### 23.4 计算口径（锁定）

- **AUC 标准误**：Hanley–McNeil。
- **所需样本量**：解 `AUC + 1.96·SE(n) < T`，`n1 = n2 = n`。两个目标阈值：
  - `T = 0.70`：判别器的临床可用下限；
  - `T = 0.77`：IMPRES 原文跨数据集 AUC 区间的**下界**。
  若点估计本身 ≥ T，判定为「不可能」——增大 n 只会让 CI 更窄地落在该值之上。
- **最小可检出差异（MDD）**：双侧备择、单侧 alpha = 0.025（与既有报告口径一致），解 `(A₁ − 0.50) = (z_{1−α} + z_{1−β})·SE(n; A₁)`。
- **元分析**：logit 尺度。固定效应 + DerSimonian–Laird 随机效应；异质性用 Cochran's Q 与 I²。
- **符号一致性**：符号检验（双侧），对每个签名统计各队列点估计是否同侧。

### 23.5 事先写死的解读规则

1. **元分析结果不覆盖单队列结果**。单队列结论照旧成立，元分析只是加一层汇总。
2. **I² > 75% 时只报随机效应**，并在正文写明队列间不可直接合并解读。
3. **符号检验 p > 0.05 时，明确写「不构成统计证据」**。`IPS-MHC+CP` 的 3/3 同向在 n=3 时 p = 0.25，**即使算出来也必须判为未复现**——这一条写死在计算之前，正是为了防止事后把 3/3 说成证据。
4. **必须写出「本节能否定什么、不能否定什么」**。已知边界：本文从未在 IMPRES 的推导队列 GSE115821 上测试（该系列 37 样本仅对应 8 例独立患者，见 `docs/02` §7.2），因此**「迁移失败」与「签名本身无效」在本文数据下不可区分**。这一句不得删。

### 24.3 事先写死的解读规则

1. **终点定义必须审计**。各队列的**原生终点**与本项目**实际使用的终点**必须分列记录。若原生终点与 IMPRES 原文（RECIST）不一致而本项目未拉回口径，则该队列的 AUC 不具可比性，须在正文明确声明。
2. **时点分层**：GSE91061 按 `visit_geo` 分 Pre / On 两层。若两层差异显著，说明信号由时点驱动，主结论的归因须改写。
3. **方案分层**：GSE215868 按 `itx` 分 IPI+NIVO / PEMBRO / NIVO 三层。若某层明显好于其他，须检验是否由方案构成解释主比较的阴性结果。
4. **分数动态范围必须先于 AUC 解释**。若某队列内签名分数近似常数，AUC 无意义。判据：分数方差中超过纯随机期望的部分占比。
5. **归因边界表必须写出「不能排除」的两项**，且不得删除：
   - **人群构成不同**（瘤种、突变、转移负荷等匹配变量不可得，无法调整）；
   - **推导队列本身可能就弱**（IMPRES 推导队列 GSE115821 仅 8 例独立患者，从未纳入）。
   因此**「不迁移」与「无效」在本文数据下不可区分**，此句为硬边界。
