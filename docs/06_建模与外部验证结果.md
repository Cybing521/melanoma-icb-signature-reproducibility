# 建模与外部验证结果

> 数据截止 2026-10-07。口径见《终点口径与分析预登记》第十五节，建模前锁定。
>
> **本文件记录一个完整的阴性结果，并由跨队列方向一致性检验支持这个阴性结论。**

## 一、一句话结论

在 GSE91061 的 33 例治疗前样本上，17 个 Hallmark 签名特征**不能区分应答与进展**（嵌套交叉验证汇总 AUC **0.500**）；唯一在开发集上看起来像信号的单个特征，在独立验证集 GSE78220 上**方向反转**；17 个特征的跨队列方向一致性为 **8/17**，与随机期望 8.5 无法区分。

## 三、主结果

| 指标 | 值 | 说明 |
|---|---|---|
| 100 个外层折 AUC 均值 | **0.5495** | 折与折之间 |
| 外层折 AUC 标准差 | **0.2565** | 折与折之间，**极大** |
| 每次重复的整体 AUC（20 次）均值 | 0.516（标准差 0.112，范围 0.291–0.683） | 重复与重复之间（样本标准差） |
| **汇总全部 out-of-fold 预测的整体 AUC** | **0.500** | 见下方警告 |
| PRCR 预测概率中位 / PD 预测概率中位 | 0.470 / 0.474 | 两组预测概率几乎完全相同 |

> **⚠️ 头条数字「0.500」的口径必须说清（2026-10-07 一致性 review 修正）**
>
> 0.500 是把 **20 次重复的全部 out-of-fold 预测合并**后算的一个 AUC，
> 等于**每位患者被重复计入 20 次**。同一套模型换另外两个口径就是不同的数：
> **折均值 0.5495**、**每重复均值 0.516 ± 0.112**。
> 三个数不矛盾，是三个统计量。**只报 0.500 会让人误以为"精确等于随机"，实际它只是三者中最保守的一个。**
> 完整的口径对照与预登记主面板的同口径结果见 `docs/08` 第三节。

每折只有 2 个阳性样本，因此单折 AUC 在 {0, 0.5, 1} 附近跳动，标准差 0.26 主要是**折间噪声**而非模型判别力。把 100 折的 out-of-fold 预测汇总起来，AUC 恰为 0.500，两组预测概率中位数几乎相同。

## 四、单特征参照与最大统计量偏倚

17 个单特征各自跑同一套嵌套 CV，**全部在同样这 33 例上评估**：

| 特征 | CV AUC | | 特征 | CV AUC |
|---|---:|---|---|---:|
| il6_jak_stat3 | **0.734** | | kras_up | 0.554 |
| ifng_response | 0.635 | | antigen_presentation | 0.554 |
| tgf_beta | 0.592 | | angiogenesis | 0.523 |
| interferon_alpha | 0.417 | | g2m_checkpoint | 0.374 |
| mtorc1 | 0.399 | | tnf_nfkb | 0.367 |
| proliferation | 0.409 | | emt | 0.361 |
| hypoxia | 0.378 | | il2_stat5 | 0.288 |
| wnt_beta_catenin | 0.308 | | glycolysis | 0.253 |

**`il6_jak_stat3` 的 0.734（嵌套 CV 单特征参照，100 外层折均值）与 0.735（全数据 33 例单变量 in-sample AUC）是同一特征在两种口径下的值，不是两个不同结果；本文其余位置一律用 0.734（CV 口径），全特征方向一致性表用 0.735（in-sample 口径）。**0.734 是 17 个里挑出来的最大值，因此系统性偏高。** 10 例阳性下 AUC 的标准误约 0.1，在 17 个独立假设都为 0 的情况下，期望最大值本就在 0.65–0.70 区间。0.734 落在该区间内，**不构成真实效应**。

同一现象在内层选择里看得更清楚：`il6_jak_stat3` 在 **100/100 折**都被选中，`tgf_beta` 51 折、`ifng_response` 50 折。但内层用的是「训练集内单变量 AUC 最极端」这一排序，**在原假设下它每折必然挑中一个纯粹由噪声造成的"极端"特征**。这是典型的最大统计量偏倚，不是特征稳定的证据。

## 五、决定性的外部验证：方向反转

`il6_jak_stat3` 在两个独立队列上：

| 队列 | PRCR 中位 | PD 中位 | AUC | 自助法 95% CI |
|---|---:|---:|---:|---|
| GSE91061（33 例，开发） | 0.738 | 0.608 | **0.735** | [0.552, 0.891] |
| GSE78220（26 例，外部） | 0.735 | **0.897** | **0.357** | [0.149, 0.595] |

> **口径更正（2026-10-07，一致性 review 时发现）**：本表 GSE78220 的 AUC 原写 **0.363** [0.167, 0.601]，
> 该数值**在患者级口径下无法复算**。按任务 14（`scripts/20`）重新计算得到 **0.357** [0.149, 0.595]，
> 且已独立复算确认可复现。差异来源是 `Pt27` 的两个解剖部位（`GSM2069842` / `GSM2069843`）
> 如何折叠为 1 例——单取其中一个位点得 0.363，**按患者级取中位数**得 0.357。
> 本项目统一采用**中位数**口径（符合《预登记》第一节「分析单位为患者，重复活检进配对/混合结构」）。
> 两者相差 60 vs 61 个配对（分母 14×12=168），**不改变任何结论**。以下全表以 0.357 为准。

**方向完全反转**：开发集里 PRCR 的 IL6-JAK-STAT3 离散度更高，验证集里反而更低。两边的置信区间都跨过 0.5。这正是"开发集上好看但换个队列就消失"的教科书形态，也证实了上一节对最大统计量偏倚的判断。

### 全特征方向一致性

## 七、结论的边界：这些结果说明了什么、没说明什么

### 说了什么

1. **在 10 例阳性的样本量下，本特征集不能区分应答与进展**，且任何在开发集上出现的信号都无法在独立队列复现。
2. **已发表的 SOTA 预测器 IMPRES 在治疗前口径下同样不能区分**（AUC 0.30–0.36），且与原文报告的 0.77–0.96 不符。
3. **17 个 Hallmark 签名在两个独立 ICB 队列间方向一致性为随机水平。**

### 没说什么

1. **不等于"免疫状态与 ICB 应答无关"**。样本量决定了我们只能排除"用这个特征集、在这个样本量下可靠区分"这个可能性。
2. **不等于 IMPRES 无效**。本项目的实现有一处无法消解的方向约定歧义（见 `docs/05` 第四节），治疗前子集也与原文口径不同。
3. **不等于单细胞层面的免疫生态位无关**。模块 2 的阴性结果受 18 个文库的效力上限约束。
4. **不能拿去当阴性对照**。这些特征在别的设计里可能有价值，只是本项目没测出来。

## 八、对方案的直接影响

方案 第七节「阴性结果」行预先写明：*"保留并报告；候选不足或不可比时，交付分布描述与一致性分析"*。本项目走到了这一分支。

**建议的后续处理（需用户确认后再执行）**：

1. **不要**继续往主模型上堆特征——33 例 / 10 阳性已经越过了能可靠建模的边界，继续做只会产出更多假阳性。
2. 若仍要保留建模这条线，**唯一值得做的是把模型降到 1 个特征**，并且只在 GSE78220 上做一次预注册的验证，而不是反复调开发集。
3. **TCGA-SKCM 背景关联（原模块 6）已于 2026-10-07 按用户决定砍除**——它是次要目标，且不构成 ICB 证据，在主结论为阴性的情况下增加篇幅只会稀释重点。方案中该节已删，原模块 7「交付物」已递补为模块 6。
4. 项目叙事若要保留，应转向**"用方向一致性检验否证了一个看似可行的特征集"**这一方法学结论本身，这比一个撑不住的预测模型更站得住。
