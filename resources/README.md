# 外部注释资源

## hallmark_2024.1.Hs.gmt

- **内容**：MSigDB Hallmark 基因集，50 个集，人类（Hs），版本 2024.1.0
- **来源**：服务器上 `/root/autodl-tmp/cad_htn_mechano_raas/metadata/hallmark_2024.1.Hs.gmt`（同服务器的既有资源，MD5 与官方发布一致）
- **用途**：模块 2 的肿瘤内在状态打分。使用注释集而非手写基因列表，是为了避免主观挑基因，并让打分口径可被第三方复现。
- **许可**：MSigDB 对学术使用免费；商业使用需申请。本项目为学术研究用途。

**引用**：Liberzon A, et al. The Molecular Signatures Database (MSigDB) hallmark gene set collection. Cell Systems. 2015;1(6):417-425.
